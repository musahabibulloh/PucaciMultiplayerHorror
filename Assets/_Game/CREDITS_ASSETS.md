# Kredit & Aset Pucaci

Dokumen ini mencatat seluruh aset pihak ketiga yang digunakan dalam proyek Pucaci sesuai dengan spesifikasi di `SKILLS/mainmenu.md`.

## Status Lisensi Aset
- **Font**: TextMeshPro default font (`LiberationSansSDF`) - Dilisensikan di bawah SIL Open Font License (OFL) / Apache 2.0 via paket TextMeshPro Unity.
- **Audio**: Tidak ada aset audio pihak ketiga eksternal yang disertakan pada implementasi menu dasar ini (hanya AudioSource placeholder).
- **Model / 3D & Animasi Karakter**: Model karakter horror (`Circle`, tekstur `mc-horror.png`) dan set animasi Mixamo (Run Forward, Running Jump, Running Slide, Jogging Stumble, Standing Up, Flying Back Death, Run Look Back).
- **Model / 3D Lingkungan**: Model `POS RONDA.fbx` dengan material dan tekstur `pos.png`.
- **UI & Tekstur**: Komponen bawaan Unity UI (UGUI) dan Canvas standard tanpa gambar berhak cipta.
